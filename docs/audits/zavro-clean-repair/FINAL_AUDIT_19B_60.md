## Ustalenia bez pełnego zamknięcia

- **ZC-AUD-002 — BLOCKED / REAL_GECKO_REQUIRED:** kolizję po resecie klucza JS pokazano w VM i Robolectric, lecz nie wystąpił potwierdzony scenariusz zachowania natywnej EngineSession po restarcie Gecko WebExtension. Nie osłabiać native high-water guard.
- **ZC-AUD-030 — OPEN (w macierzy BLOCKED):** mismatch `Store.contextId` i nowego engine istnieje w kodzie, ale rzeczywista izolacja `OriginAttributes` oraz cookies/storage dla `window.open` i `target=_blank` nie jest potwierdzona. Nie wolno twierdzić o wycieku.
- **ZC-AUD-031 — PARTIAL (w macierzy FAIL warunku pełnego zamknięcia):** tombstone/retry/SessionStorage barrier mają testy, ale void `clearDataForSessionContext` nie daje dowodu trwałego usunięcia. Wymagany izolowany delete/relaunch i sprawdzenie pozostałych profili.
- **ZC-AUD-043 — CONDITIONAL_GUARD (w macierzy NOT_TESTED):** fixture DOM i JS chronią metadane przed pobraniem z poprzedniego `currentSrc`, jednak nie ma rzeczywistej kolejności eventów Gecko dla źródeł A/B.
