## Zastosowanie
Wklej blok do pola Instrukcje projektu „Przeglądarka” **zamiast starego**, nie dopisuj drugiego. Repozytorium nie zmienia samo ustawień projektu, personalizacji ChatGPT, ustawień Codex czy statycznych załączonych plików Źródła. Codex w repo czyta też kanoniczny `AGENTS.md`, a Work / zwykły chat powinny stosować ten sam bootstrap. Po zmianie plików Źródeł projektu ich kopie trzeba ręcznie odświeżyć, jeżeli nadal są używane.
